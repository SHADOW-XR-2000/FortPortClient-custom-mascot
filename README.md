# FortPortClient-custom-mascot
Это пак скинов и реплик. А еще можно скачать Example и сделать свой скин. (образцы анимаций и реплик)

# Установка скина:
- скачайте зипку
- зайдите в настройки профиля - кастомизация
- Нажмите "импорт" и выберите зипку
- В меню выбрать скин
- Применить, сохранить и радуемся

# Как создать свое:
Видео должны быть формата webm VP9 с поддержкой прозрачности. Ширина-высота можно свои, но желательно как у оригинала. Продолжительность не ограничена, но лучше ставить зацикленное не более 3 сек.

/E0/ - mascot-peek.webm - выглядывает (состояние по умолчанию при появлении);
/E1/ - mascot-lookout.webm - осматривается, привлекает внимание;
/E2/ - mascot-wave.webm - машет рукой: приветствия, обычные реплики;
/E3/ - mascot-killed.webm - «убит» (играется один раз, когда в него кидают кирпич);
/E4/ - mascot-stand.webm - спокойно стоит (после закрытия плашки);
/E5/ - mascot-think.webm - задумался;
/E6/ - mascot-blush.webm - смущается;
/E7/ - mascot-yell.webm - кричит.

Маркер можно постааить в начале реплики внутри "кавычек", например: "/E4/ шавуху охота".
